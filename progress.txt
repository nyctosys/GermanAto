# Progress log (append-only, Ralph style)

## Codebase patterns
- API: FastAPI + SQLAlchemy 2 sync in api/app; routers in api/app/routers; models in api/app/models.py; one Alembic revision per story that changes tables (autogenerate, then check with `alembic check`).
- New numbered documents: add the kind to api/app/numbering.py PREFIXES, call next_number(db, actor.branch, kind).
- Permissions live in api/app/permissions.py; routes use require("perm"); add the permission there and to DEFAULT_ROLES where it fits.
- Money records always carry proof_id or no_proof_reason (CHECK constraint) and reuse estimates.Proof; bank/wallet need a reference or screenshot.
- Stock only changes through app.stock.move(); do not db.refresh() an item after move() (it discards the unflushed average cost).
- Web: Next.js 16 App Router, Tailwind v4 tokens in globals.css, zustand for shared state, zod schemas in web/lib/schemas.ts with parseForm; shared components in web/components (ui, payments, estimates, purchasing, print).
- Pressable things must look pressable (DESIGN.md 6b): filled ghost buttons, underlined links, chevron on whole-row links (class row-link).
- After editing globals.css, Turbopack may serve stale CSS: stop the web preview, rm -rf web/.next/dev, restart.
- Browser checks: scan every new screen at 320/375/768/1280 for sideways scroll, clipped text, small touch targets.
- Push: git -c credential.https://github.com.helper= -c 'credential.https://github.com.helper=!/usr/local/bin/gh auth git-credential' push https://github.com/nyctosys/GermanAto.git dev:refs/heads/dev

## US-601 to US-604 (HR)
- Attendance days come from app/attendance.py summarise(); payroll uses the same function, so screens and pay always agree. TIMEZONE env (default Asia/Karachi) turns device wall-clock times into UTC.
- Device push is /iclock/cdata (no session): registered serial + optional secret via ?token= or X-Device-Secret. Resends are ignored; unknown pins are kept and claimed when an employee gets that device number.
- A day's pay = salary / working days in the month; deduction = (absent + unpaid leave) days; late days cost nothing. Salary advances are MoneyEntry kind salary_advance (Dr 1300 Employee advances); payroll approval posts Dr 6100 / Cr 1300 recovery / Cr 2400 net; paying posts Dr 2400 / Cr money.
- Next.js pages cannot export extra names: shared constants belong in components/.
- Layout checker (touching cards/controls, overflow) lives in this session's notes: scan sibling section.rounded-card gaps < 8px and controls < 6px apart; section pills on the inspection page were the only offender.

## US-902 to US-904 (sync)
- app/sync.py applies events with Core statements (skips the audit/outbox hook so nothing echoes back); (origin_branch_id, origin_seq) in sync_inbox is the idempotency key; apply_events stops at the first failure so order is kept and returns the last safe seq (acked).
- Conflict = same version, different content (ignoring updated_at/by). Known limit written in the guide: unequal edit counts resolve silently to the higher version.
- Worker is sync_worker.run_once(db, branch, transport) so tests use a fake transport; HttpTransport is stdlib urllib. Pull cursor skips rows it filters out so it never stalls.
- Tokens live in sync_credentials (hash only), not on branches, because branch rows themselves are synced.
- Conflict list is stacked rows, not a table: tables scrolled sideways at 320px.
